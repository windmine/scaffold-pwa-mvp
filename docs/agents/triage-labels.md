# Triage labels

Use these exact label strings for the corresponding triage roles:

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Maintainer needs to evaluate the issue. |
| Needs information | `needs-info` | Waiting for the reporter to provide information. |
| Ready for an agent | `ready-for-agent` | Fully specified and ready for an agent to implement. |
| Ready for a human | `ready-for-human` | Requires human implementation. |
| Will not fix | `wontfix` | Will not be actioned. |

These are the selected conventions, not evidence that the remote labels already exist. Inspect existing GitHub labels before an authorized triage operation; this setup does not create them.
