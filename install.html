This may be an in-app browser. Use its menu to open this page in Safari or Chrome. You can also copy the installation link below.

iPhone / iPad
  1. Open this page in Safari.
  2. Tap Share (or More, then Share).
  3. Choose Add to Home Screen.
  4. Keep Open as Web App on if shown, then tap Add.
Android
  1. Open this page in Chrome.
  2. Tap Install ReportFlow above if it appears.
  3. Otherwise, open Chrome's menu and choose Install or Add to Home screen. Some versions list it under Install and create shortcut.
  4. Confirm installation, then open ReportFlow from its icon.
